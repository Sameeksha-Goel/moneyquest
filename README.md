# MoneyQuest RPG 💰⚔️

A gamified personal finance tracker where managing your money feels like playing an RPG. Log expenses, complete quests, defeat financial bosses, and level up your character as you build better money habits.

## Features

- **RPG Progression** — earn XP and level up through 7 character classes (Seedling → Legend)
- **Quest System** — daily and weekly financial challenges that reset automatically
- **Boss Battles** — defeat enemies like *The Emergency Goblin* by hitting real savings milestones
- **Expense Tracker** — log spending by category with budget bars and monthly analytics
- **Achievements** — 12 unlockable badges tied to financial milestones
- **Streak Tracking** — saving, logging, and quest streaks with visual indicators
- **Penalty System** — lose XP for impulse buys and blown budgets
- **Daily Login Bonus** — streak-based XP rewards for consistent use

## Tech Stack

- Vanilla HTML, CSS, JavaScript (no frameworks)
- Chart.js for the spending doughnut chart
- localStorage for persistent game state
- Fully responsive, mobile-first layout

## Run Locally

No setup needed — just open `index.html` in any browser.
